# Aplicativo de Cinema - Grupo 12

## Objetivo
Aplicativo mobile para centralizar trailers, sinopses, avaliações, programação de cinemas locais e compra de ingressos[cite: 2].

## Definição da Proof of Concept
### 1.	Objetivo da PoC
Demonstrar a viabilidade do aplicativo por meio da implementação de um fluxo criado com base na jornada de um usuário que visa encontrar filmes nacionais, consultar informações sobre um filme de interesse e visualizar as suas sessões disponíveis.
### 2.	Escopo da PoC
-	Exibição de filmes em cartaz
-	Filtro de filmes nacionais
-	Visualização de informações de um filme
-	Consulta de sessões
### 3. Dados Utilizados na PoC
Para evitar a necessidade de integração com APIs externas de filmes, cinemas, ou de geolocalização, os dados dos filmes e sessões serão cadastrados diretamente no banco de dados do aplicativo.

## Como rodar o projeto[cite: 1]

**Frontend:**
1. Abra o terminal e digite: `cd frontend`
2. Inicie o app: `npx expo start`

**Backend:**
1. Abra o terminal e digite: `cd backend`
2. Inicie o servidor: `npm start`
